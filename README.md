# another me

以经历为起点，想象另一种人生。React 前端和 Node API；故事为 AI 虚构，不是未来预测。

## 本地开发
需要 Node.js 24。执行 npm ci，再复制 .env.example 为 .env 并自行填写密钥，运行 npm run dev，打开 http://127.0.0.1:5173/ 。Ctrl+C 停止。修改服务端配置后重启。已有 Windows 启停脚本保留。

## Render 生产部署
完整步骤见 [部署说明](docs/deployment.md)。运行 npm ci --include=dev && npm run build 构建，npm start 启动。一个 Node 服务提供 dist 和同源 /api；生产不使用 Vite，不读取本地 .env。

密钥只通过服务端 MINIMAX_API_KEY 环境变量注入。没有密钥为明确演示模式；真实请求失败不替换成演示内容。国内与国际站配置不能混用。

## 保存与限制
故事、聊天和记忆保存在当前浏览器，不提供账号同步。手机、新域名、云浏览器不会自动带入电脑 localhost 的存档。聊天收尾在浏览器本地整理记忆，可以编辑删除；没有额外记忆模型接口。

生产接口有请求体、字段长度、每分钟请求和全局并发保护，无累计聊天条数限制。单实例暂只允许一条模型请求同时进行。限流仅为基础保护，不是身份认证；公开链接仍可被他人使用。服务重启后临时会话重建，浏览器存档保留。

## 验证
npm run build 后执行 npm test。公开仓库仅包含无个人背景的生产部署回归；更早的本地案例和台账保留本机、不上传。部署适配本地完整回归108项通过，生产端口烟雾测试包含SPA刷新、健康检查、静态文件保护、模拟故事和流式回复、长度与限流。没有新增收费模型调用，Render实际启动与公网流式传输待部署后验证。
